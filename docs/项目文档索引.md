# RAG-HC 项目文档索引

## 1. 文档目的

本索引文件用于帮助项目成员快速定位当前仓库中的开发资料，并明确各文档的用途与阅读顺序。

## 2. 文档清单

### 2.1 项目开发文档

- 文件：`docs/项目开发文档.md`
- 用途：完整介绍项目背景、架构设计、模块说明、数据契约、环境配置、部署建议和优化路线。
- 适合对象：开发、测试、交付、汇报人员。

### 2.2 Word 交付文档

- 文件：`deliverables/RAG-HC_项目开发文档.docx`
- 用途：用于对外发送、内部归档、打印或作为正式交付材料。
- 适合对象：项目经理、客户接口人、汇报对象、管理层。

### 2.3 导出脚本

- 文件：`scripts/export-docs.mjs`
- 用途：将 Markdown 文档转换为 Word 文档。
- 适合对象：维护交付资料的开发人员。

## 3. 推荐阅读顺序

1. 先阅读 `docs/项目开发文档.md` 了解完整项目情况。
2. 如需对外发送材料，优先使用 `deliverables/RAG-HC_项目开发文档.docx`。
3. 如需修改文档后重新导出，执行 `node scripts/export-docs.mjs`。

## 4. 维护说明

- 当项目结构、模块职责、部署方式或技术栈发生变化时，应同步更新开发文档。
- 每次正式交付前，建议重新导出一次 Word 文件，确保内容与仓库当前版本一致。
